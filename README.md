# Say Hi to Donnie Gardner the 3rd 👋

A single-page website dedicated to saying hi to **Donnie Gardner the 3rd** — funny, friendly, and (slightly) inspiring.

## Live Site

[https://kjw3.github.io/say-hi-to-donnie/](https://kjw3.github.io/say-hi-to-donnie/)

## What's on the page

- An animated waving hand and shimmering gradient headline
- A twinkling starfield background
- A **"Say Hi to Donnie"** button that:
  - Fires a confetti burst
  - Cycles through funny messages ("THE 3RD HAS BEEN NOTIFIED!", "LEGENDARY. ICONIC. DONNIE.")
  - Keeps a persistent hi-count in your browser's `localStorage`
- Cards with a Formal Declaration of Friendship, an inspiring message, three facts about greatness, and a mission statement
- Scroll-reveal animations throughout

## Tech

Pure HTML, CSS, and vanilla JavaScript — no build step, no dependencies. Just open `index.html`.

## Hosting

Deployed on **GitHub Pages** (legacy build type, `main` branch, root path). Push to `main` and the site updates automatically.
